## Review Notes (심사 정보 → 메모란에 붙여넣기)

```
Thank you for reviewing Paxo.

WHAT IT DOES
Paxo is a menu bar study assistant. When the user presses a global hotkey (Option+Command+S), they select a region of their screen containing a study problem. The captured image is sent to our server, which forwards it to the Google Gemini API to generate an answer WITH a step-by-step explanation. Paxo is a learning tool: explanations are always available — the "quick self-grading" display option only collapses the explanation behind one click, it never removes it.

HOW TO TEST
1. Launch the app — an onboarding window appears. No account or sign-in is required.
2. Grant Screen Recording permission when prompted (System Settings > Privacy & Security > Screen & System Audio Recording). A relaunch may be needed after granting.
3. Open any study problem on screen (e.g., a math problem in a browser or PDF), press Option+Command+S, and drag to select the problem area.
4. The answer appears in a floating panel within seconds, followed by the explanation.
5. Free tier is 3 solves/day; afterwards the paywall appears. Subscriptions (monthly/yearly, 7-day free trial) unlock unlimited use.

PRIVACY / PERMISSIONS
- Screen Recording permission is used ONLY when the user explicitly triggers a capture via the hotkey or menu. There is no background or continuous capture.
- Captured images are used solely to generate the solution, are not stored on our servers, and are discarded immediately after processing.
- No account, no personal data collected. A random anonymous device ID is used for rate limiting only.

AI DISCLOSURE
Solutions and explanations are AI-generated (Google Gemini API) and the app labels them as reference material.
```
